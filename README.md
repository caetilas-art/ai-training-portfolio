### Evaluation Criteria

Responses will be evaluated based on:

| Criterion | Description |
|---|---|
| Accuracy | Is the information correct and reliable? |
| Relevance | Does the response directly address the user's request? |
| Clarity | Is the response clear and easy to understand? |
| Completeness | Does the response provide enough information? |
| Safety | Does the response avoid potentially harmful or inappropriate content? |
